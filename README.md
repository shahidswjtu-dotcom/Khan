# Peridynamics source recovery and builds

The recovered peridynamics implementations and their historical versions are in
[peridynamics/](peridynamics/README.md). The existing results PDF is in
[reports/](reports/).

Start with `peridynamics/versions/workspace/bowen_from_scratch/` for the independent
Python reconstruction, or `peridynamics/versions/workspace/bowen_reproduction/`
for the earlier Python engines and preserved notebooks. Original and corrected
Fortran sources are retained separately inside the archive snapshots.

Every recovered file has its original provenance and SHA-256 recorded in
`peridynamics/RECOVERY_MANIFEST.json`. Build instructions and current verification
results are linked from the source index.
